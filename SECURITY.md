# Security Policy

## Supported versions

Primitiv follows [semantic versioning](https://semver.org/). Security fixes are issued for the current minor release line.

| Version | Supported |
|---------|-----------|
| 1.5.x   | ✅        |
| < 1.5   | ❌        |

## Reporting a vulnerability

**Please do not open a public GitHub issue for security reports.**

Report vulnerabilities privately through one of these channels:

- **GitHub Private Vulnerability Reporting** (preferred) — [github.com/AI-by-design/primitiv/security/advisories/new](https://github.com/AI-by-design/primitiv/security/advisories/new)
- **Email** — ana.state88@gmail.com

Please include as much of the following as you can:

- Affected version (or commit SHA)
- Steps to reproduce, ideally with a minimal example
- Impact — what an attacker could do
- Any suggested mitigation

## Response

I aim to:

- **Acknowledge** your report within 72 hours
- **Confirm or dismiss** the issue and propose a fix or mitigation within 7 days
- **Coordinate a disclosure window** with you before publishing details, so users can upgrade before the vulnerability is public

Thank you for helping keep Primitiv and its users safe.
